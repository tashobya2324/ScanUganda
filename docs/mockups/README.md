# Flow mockups (reference only)

`prototype/` is the original Figma Make mockup: a phone frame showing the screens, a feature-phone showing the USSD dialogue, and a sidebar to jump between them. It was made to show **how the system should flow**, not how it should look or be built, so it is **not served or compiled** by the project any more.

What it is still useful for:
- The screen order: onboarding → home → scan → green / yellow / red result → report → history → profile.
- The USSD dialogue idea, dialled as `*284*CODE#` (see PLAN §5 and Phase 5).

The real products are `apps/console` (web system) and `apps/pwa` (mobile app); their look follows `docs/DESIGN.md`.
